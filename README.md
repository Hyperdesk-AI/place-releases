# Place for Mac

Download Place for Mac for Apple Silicon (M-series Macs).

- [Place for Mac 0.1.1 Beta](https://github.com/Hyperdesk-AI/place-releases/releases/tag/v0.1.1-beta.1)
- [All releases](https://github.com/Hyperdesk-AI/place-releases/releases)

To install, open the `.dmg` and drag **Place** to **Applications**. Open Place and select **Continue with Google**. Connecting Gmail requires an approved beta account.

The current beta build is ad hoc signed and has yet to be notarized. macOS may block it on first launch.
